## 🚀 Featured Work

### 💰 FinFlow — Cloud-Native Personal Finance Platform

**Next.js • Node.js • Express • PostgreSQL • Prisma • AWS (S3, CloudFront, App Runner, SES) • Docker • Terraform • GitHub Actions**

A full stack personal finance platform with 10+ RESTful APIs across 7 modules for budget tracking, automated bill reminders, financial analytics (Recharts), and PDF/CSV reporting. Secured with JWT + HTTP-only cookies, CSRF protection, and bcrypt hashing. Frontend delivery is decoupled through S3 + CloudFront (with OAC) for sub-100ms global latency, and the backend is containerized on AWS App Runner with a full Terraform + GitHub Actions CI/CD pipeline.

### 🖼️ PixelsBazar — Responsive Image Gallery Platform

**React.js • Tailwind CSS • Aceternity UI • Firebase Authentication • Unsplash API**

A fully responsive image gallery consuming the Unsplash API, with keyword search, one click full quality downloads, and infinite scroll pagination. Auth is handled via Firebase (Google OAuth + Email/Password) with protected routes, and the UI is polished with Aceternity UI's animated components.

### 🎫 AI-Powered Helpdesk (Steora)

**Next.js • Node.js • Prisma ORM • PostgreSQL (Supabase) • Tailwind CSS**

A full-stack helpdesk with role-based auth, AI-based ticket classification and priority prediction, duplicate ticket detection, multi-team assignment, and a centralized admin dashboard — cutting manual ticket triaging effort by ~80% and manual coordination by ~60%.
